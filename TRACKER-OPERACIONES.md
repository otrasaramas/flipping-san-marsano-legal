## Cómo Usar Este Tracker

1. **Renombra las carpetas** → reemplaza `flipping-01-nombre` con algo descriptivo (p. ej. `flipping-01-san-marsano-apto-504`).
2. **Completa los campos [ ]** → matrícula, dirección, responsables, fechas.
3. **Actualiza estados** → cambia 🔴 → 🟡 → ✅ conforme avanzas.
4. **Guarda el archivo** → git commit + push cada vez que haya cambios importantes.
